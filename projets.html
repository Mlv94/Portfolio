🪟 Infrastructure Windows

Serveur Windows Server & Active Directory

Déploiement d'un serveur Windows virtuel avec un annuaire Active Directory complet et une politique de sécurité appliquée par GPO à l'ensemble des postes clients.

  • ✔ Installation et configuration d'Active Directory Domain Services (AD DS) : création du domaine, des unités d'organisation et des comptes utilisateurs
  • ✔ Rédaction de stratégies de groupe (GPO) interdisant l'accès au Panneau de configuration pour les comptes standards
  • ✔ Mise en place d'une politique de gestion des mots de passe (complexité, durée de validité, verrouillage de compte) via GPO
  • ✔ Ajout et organisation des utilisateurs dans l'annuaire, avec attribution des droits selon les unités d'organisation
🪟 Windows Server 2022 🛂 Active Directory 🛡️ GPO 🌐 VirtualBox

🖥️ Gestion de parc

GLPI & FusionInventory

Mise en place d'un outil de gestion de parc informatique (GLPI) couplé au plugin FusionInventory pour automatiser l'inventaire matériel et logiciel du parc.

  • ✔ Installation et configuration de GLPI (serveur web, base de données MySQL) pour centraliser la gestion des équipements et des tickets
  • ✔ Installation du plugin FusionInventory et déploiement de l'agent sur les postes clients
  • ✔ Configuration des tâches d'inventaire automatique (matériel, logiciels, réseau) remontées automatiquement vers GLPI
  • ✔ Organisation du parc (entités, catégories, états) pour un suivi précis du matériel
🗂️ GLPI 📦 FusionInventory 🐬 MySQL 🌐 Apache
