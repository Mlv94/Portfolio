Chiffrement du portfolio

Outil pour modifier les pages protégées par mot de passe. Tout se passe dans votre navigateur : aucun fichier ni mot de passe n'est envoyé sur Internet.

Comment ça marche

  1. Pour modifier une page : déposez ici la page en ligne (ex. competences.html téléchargée depuis GitHub). L'outil la déchiffre et vous rend la version lisible.
  2. Modifiez cette version lisible avec votre éditeur habituel.
  3. Déposez-la à nouveau ici : l'outil la chiffre.
  4. Envoyez le fichier chiffré sur GitHub (« Add file » → « Upload files »), à la place de l'ancien.

L'outil détecte tout seul si un fichier est chiffré ou non. Ne mettez jamais la version lisible sur GitHub : le dépôt est public.

Vous pouvez sélectionner plusieurs pages d'un coup.

Fichiers prêts

    Changer le mot de passe

    Déchiffrez toutes les pages avec l'ancien mot de passe, puis chiffrez-les toutes avec le nouveau et remplacez-les sur GitHub. Les visiteurs déjà connectés devront saisir le nouveau mot de passe.

    Choisissez un mot de passe long : au moins 4 mots sans rapport entre eux, ou 16 caractères minimum.
